如何取得 PDB

  1. 在執行 PDB 轉檔工具 的電腦上，確認來源檔案與輸出資料夾都已存在。
  2. 用 PDB 轉檔工具 開啟下載的 .ixl，選取文件並執行轉換。
  3. 到設定的輸出位置取得 .pdb。

直接上傳檔案轉換

下載上方 Windows 工作台並解壓縮，執行 Start.cmd，首次選擇原廠 轉檔引擎 ZIP 或執行檔，即可進入本機網頁。

格式、原廠引擎與專案參考

PalmDOC 可直接在瀏覽器製作與閱讀。圖文 PDB（SDoc / SilX）目前提供結構檢視；寫入及執行 IXL 轉檔設定需使用 Windows 原廠引擎。在 Windows 工作台執行 Run-Project.cmd，可選取 .ixl 和選用的 .ixs，確認目的地後批次轉檔。排程時間寫在 IXL 裡，執行時需要支援排程的原廠程式。

網頁合訂僅能直接抓取允許瀏覽器讀取的網站。也可以選取已存好的 HTML 資料夾。書架和編輯草稿儲存在目前瀏覽器，請使用匯出功能備份。

功能研究參考 YPSongbook、ministry、palm-pdb、HarmonyPDB-Next 與 PyPlucker。工作頁內的功能採獨立實作。
