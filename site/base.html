PDB 文件轉檔

下載 Windows 工作台，解壓縮並啟動後，在本機網頁使用 轉檔引擎建立 圖文 PDB。需備妥官方轉檔程式。

.PDB

建立 PDB 轉檔專案

設定書名、來源與輸出位置，下載 PDB 轉檔工具 可開啟的 .ixl 專案。

0 只收來源，1 加入下一層。

如何取得 PDB

  1. 在執行 PDB 轉檔工具 的電腦上，確認來源檔案與輸出資料夾都已存在。
  2. 用 PDB 轉檔工具 開啟下載的 .ixl，選取文件並執行轉換。
  3. 到設定的輸出位置取得 .pdb。

直接上傳檔案轉換

下載上方 Windows 工作台並解壓縮，執行 Start.cmd，首次選擇原廠 轉檔引擎 ZIP 或執行檔，即可進入本機網頁。
